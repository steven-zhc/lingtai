2026-11-26 operator 定的结构。位置栏：Lingtai / 项目 ▾ / 视图（Tickets · PRs · Recipe）/ 一个对象。URL 照同样的层次：/p/<project>/tickets、/p/<project>/tickets/<n>、/p/<project>/prs/<n>、/p/<project>/recipe。Report 是全局的，在右边框架里；Setup 也是全局的，但没有常驻入口：添加项目时从项目菜单「add a repository」进，GitHub App、Claude token 在需要时由提示或 ⌘K 带进去。两者 URL 都不带项目。Backlog 的 URL 先改成 /p/<project>/backlog，但还没想好它的逻辑，暂时不放进视图。每页先是 URL（旧 → 新），再是新的位置栏；黄框是已定的决定。

规则：/p/<project>/<view>[/<id>]，位置栏是同一串：Lingtai / project ▾ / view / id。全局页 /report、/setup/<step>。页面自己的事实放页面第一行，不进位置栏；数据新不新由健康圆点说，不再挂 current。旧 URL 全部永久跳转到新的，旧链接（issue 里、终端里打印的）不失效。
