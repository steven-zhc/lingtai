Bringing main into your PR

When you submit a PR, and when a pr-fix lands on it, Lingtai checks whether the team's main has moved. If it has, main's new work comes down into the PR's branch, so the team reviews it on today's code — and the PR branch is then merged back into your own branch. Nothing else waits for it: tickets go on being taken the whole time.

The card is the same small graph: main's new work coming down, the node amber while an agent resolves, the round it is on. It lives on the PR page, never on the ticket board, and it stops nothing else; while it waits, only the PRs view's count says so.
