For
  • The IDE feel: every view of a project is one icon on one rail, always in the same place
  • Room to grow — verify, discussions, a release view later — without touching the bar
  • Back is the same move as there; the lit icon says where you are
  • Recipe and Report move off the bar, which leaves it filter · health · headline and Pause
Against
  • The largest change: every page gains a rail, solo projects too (with only Tickets, Recipe, Report on it)
  • Report is the window's, not the project's; on a project rail it reads as the project's
  • Icons need hovering until learnt; 44px less width for the columns
