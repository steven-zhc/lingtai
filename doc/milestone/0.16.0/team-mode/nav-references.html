Mock · how six other tools lay out the same problem — one place, several views, several projects. Each is drawn as a plain wireframe holding Lingtai's own content, not the tool's look; under it, what that design does and what Lingtai could borrow. Design 1 (the rail) stays the working choice; this page is for picking what to add to it. Sources are the vendors' own changelogs and docs, linked under each.

If design 1 takes from these — a suggestion, not a decision

  1. Keep: the rail with one icon per view, the project square at its top (frame A of nav-rail.html), expandable to words.
  2. Add from Linear: a Waiting on you icon at the very top of the rail, above the project — every project's waiting tickets and PRs on one page.
  3. Add from Vercel: PRs at All projects too, grouped by project, so the rail never changes shape when the project does.
  4. Add from Graphite: on a PR's page, the stack — stack 2/3 and a step to the PR under or over.
  5. Leave for later: a customisable rail (Atlassian), a right-hand rail of panels (JetBrains), a list view of PRs (Graphite).
