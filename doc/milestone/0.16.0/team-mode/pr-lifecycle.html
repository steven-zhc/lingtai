团队要求修改

评论只在平台上，灵台不读；PR 留在 In review。人开一张 lingtai:pr-fix 票，做的时候 PR 也还在 In review。 它排在所有票前面，从 PR 分支切出、落在 PR 分支上；落地时发现分支被别人推过，同样按第 4 步合进来 新。 落地后 PR 回到 In progress，从第 2 步重新走；平台上的 PR 一直是 ready，不退回草稿 新。

合进 main 之后

灵台得知合并（git 可达，或平台报告），PR 进 Merged，关掉它的票。squash 合并且分支被删时，按分支名抓不到最后的 head， 就按 refs/pull/<n>/head 去抓，用完删掉；两种都抓不到，算“未证实”，不关票 新。

关闭但没合并

PR 回到 Draft；票留在个人分支上，什么都不回滚。在平台上重新打开的 PR 不再跟踪。
