## The principle of the fifth part

When something fails, a **rule** answers it first (no agent, no cost), then a
**judge** declared at `proposed` (an agent, bounded by rounds); only what
neither can answer becomes a wait, and there **triage** writes the report a
person reads — it advises and never acts. Money, releases and product
decisions stay a person's on purpose. Every automatic path sits inside one
total per attempt, and continues saved work rather than doing it again.

## Where the fifth part stands

On 2026-11-12/13 a night of unattended work stopped for a person four times
when a rule could have answered: a Cloudflare 403 cut off #1109's agent; a
GitHub 500 refused #1068's push; a flaky test (#1130) made the base read red
twice and held #1109 and #1111; and the rules that would answer these are
spread over six files (`packages/repo/src/network.ts`,
`packages/github/src/app.ts`, `packages/conductor/src/never-started.ts`,
`packages/conductor/src/judge.ts`'s `BUILT_IN_FOR`,
`packages/domain/src/routing.ts`, `packages/domain/src/attribution.ts`).

## The fifth part's decisions, as written

| Decision | Where |
|---|---|
| One total for every automatic path, counted per attempt; conflict rounds counted apart, bounded by `rounds`; `BASE_MERGES_LIMIT` 10 and `TRANSIENT_RETRIES_LIMIT` 3 as constants | [0108](../../decisions/0108-a-refusal-buys-a-round.md) §8 |
| A run a transient error cut off is rerun in place, in the same attempt | 0108 §12 |
| A red base puts the item back in the queue as `base-red`; it continues from its saved head when the base is green | 0108 §13, [0122](../../decisions/0122-several-passes-share-one-conductor.md) §2 |
| A landing refused for a transient reason is retried from its saved head | 0108 §15 |
| A red check runs twice; a flaky red that is not the diff's does not stop it | 0108 §17 |
| Every other router reason has its answer | 0108 §18 |
| Every failure rule is one module, as tables, with the docs generated from them | 0108 §19 |
| An account is a platform's, and a rate limit is its lock | [0126](../../decisions/0126-a-stop-is-a-lock-and-an-unlock.md) §2 |
| A project with work queued and nothing running says why | 0122 §8 |
| Triage reports, never acts | 0108 §16, [0118](../../decisions/0118-a-hold-explains-itself.md) |

## Not in 0.15.0 (the fifth part)

- Errors the daemon swallows and repeats (`it.status is not a function`):
  parked, no model yet.
- Triage or a judge approving a merge.
- Notifications outside the board and the CLI.
- Retrying a GitHub API call by status beyond the rate-limit lock.
- Codex's own error sentences: rows are added when a run prints them.
