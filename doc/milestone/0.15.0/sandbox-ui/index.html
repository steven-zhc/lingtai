How Claude Code signs in here

A sandboxed Claude Code run uses a long-lived token of its own (lingtai token claude). It never reads your login.

Not covered

  • Codex's login stays readable to a Codex run.
  • srt does not report a refused file read or write.
  • srt is a research preview, pinned per run.
