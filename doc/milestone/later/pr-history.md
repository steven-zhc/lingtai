# Later — the PR history

**Status** proposed, not scheduled · 2026-11-20, left out of 0.16.0 by the
operator ([0130](../../decisions/0130-a-project-is-solo-or-team.md) §6).

In 0.16.0 the PR page shows the one PR in flight; once it is merged the page
moves on to the next draft, and earlier PRs are not shown.

A history would list, newest first, the PRs submitted from this personal
branch — the code host's number, the tickets each held, how it ended (merged,
or closed and its tickets carried into a later one), and when — folded at the
foot of the PR page, the last five shown. It answers *which PR took this
ticket to main* (the task page would link to it) and *where did a closed PR's
tickets go*.

It needs no new recording: preparing, submitting, merging and closing are
already on the log (0130 §6); this is a reading of it.
