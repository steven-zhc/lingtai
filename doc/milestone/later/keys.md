# More keys, after 0.16

0.16 ships four keys and `#` (`doc/design/the-bar.md`, *the place line*),
deliberately: a long list of shortcuts in front of a new person reads as a
burden before it reads as speed (2026-11-20). Considered and left for when the
four are known to be used:

- `G R` recipe, `G O` report, `G W` the first thing waiting on you.
- On a board: `J` / `K` between cards, `H` / `L` between columns, `Enter` to
  open, `Esc` back.
- On a PR: `[` / `]` the PR under or over it in its stack, `O` open it on the
  code host.
- `?` listing them all.
