## Design: #729, what the Diff tab's fact and panels count

### Where it goes

All of it is in `apps/board/src/app/task/[id]/page.tsx`. The fold already has everything this needs, so `src/lib/task.ts` does not change:

- `run.diff` is `{ branch, files, insertions, deletions } | null` (`task.ts:304`).
- `RunProducedDiff` fills it (`task.ts:1287-1294`).
- `run.attempt` is the number that `Of` prints as `attempt {run.attempt}` (`page.tsx:530-531`).

Take the fact out of `Record` and put it in a pure, exported function: `diffFact(runs: readonly RunView[]): string`. Then `Record`'s `fact:` for the diff tab (`page.tsx:612`) is `diffFact(task.runs)`.

- Export it from `page.tsx` the way `RECORD_TABS` is exported. `unit/task-page.test.tsx:26` already imports `RECORD_TABS` and `TaskBody` from that file, so it loads in the unit project.
- Put the five cases from *Done when* in a `describe('the Diff tab’s fact (#729)')` in `unit/task-page.test.tsx`, with `RunView` fixtures. Do not render the whole `Record` for them.
- For the panel, render one `Record` with a single run (`files: []`, `diff: { files: 2, … }`) through `renderToStaticMarkup`, which that file already uses. Assert the line text, and that `RunDiff` is still there. `RunDiff` needs `baseSha` and `headSha` set (`proposed`, `page.tsx:556-557`).

### `diffFact`: the rule, in order

`task.runs` is oldest first: `Record` reverses it to get `newest` (`page.tsx:546`).

1. Find `counted`, the last run with `diff !== null`.
2. If `counted` exists and `counted.diff.files > 0`, the fact is `plural(counted.diff.files, 'file')`. If `counted` is not the last element of `runs`, add `` ` · attempt ${counted.attempt}` ``.
3. Otherwise, use today's rule unchanged:
   - `paths` is the union of paths across runs (`page.tsx:552`).
   - `paths === 0 ? 'none touched' : plural(paths, 'path')`.

   This covers "no attempt has a diff" and "the newest diff says 0". The word stays `path` and not `file`, on purpose: it is a different source and a different noun.

### Decisions the ticket does not spell out

**A `files: 0` diff is not skipped in favour of an older non-zero one.** The ticket says "the newest attempt's count is the change as it stands". A fix round that reverted everything would also read 0, and an older attempt's 2 would then be a false claim. So a 0 drops to the path-count fallback, never back to an earlier attempt.

**No `· attempt N` suffix in the fallback.** The union of paths is today's figure, and today's figure names no attempt.

**The panel line shows whenever `run.diff.files > 0`, not only when `run.files` is empty.**
- The ticket's *Want* says git's count is shown and the per-path list goes "under it when there is one". *Done when* requires that the list still appears.
- So, for each run in `newest`:
  - if `run.diff !== null && run.diff.files > 0`, render the git line and then the `flist` if `run.files.length > 0`;
  - else, if `run.files.length > 0`, render the `flist` as today;
  - else, `This attempt touched no files.` as today.
- That last case covers both `diff === null` and `diff.files === 0` with no paths, which is "git found no change either".
- The `RunDiff` button line after it does not change.

**The panel line's format** is `` `${plural(files, 'file')}, +${insertions} −${deletions}` ``, then `` `, on ${branch}` `` only when `branch !== ''`.
- The fold writes `String(d['branch'] ?? '')` (`task.ts:1290`), so an empty branch is possible and must not print `on `.
- Use the same U+2212 `−` that the attempt row uses (`page.tsx:272`). An ASCII hyphen there and a minus sign in the row would be two notations for one fact.
- Give it a class that already exists (`.empty` is wrong: this is not an empty state). A plain `<p>` is enough. No CSS changes.

### What not to touch

- `plural` is file-local (`page.tsx:534`). `diffFact` lives in the same file and uses it. Do not move it.
- The Attempts row's `2f +4 −2` (`page.tsx:272`) stays as it is.
- No ADR is affected. 0118 §2 / #417 decide that there are five tabs, each with a one-line fact, not what the Diff fact counts.
