## The decision the ticket leaves open: the import direction

`failure/respond.ts` imports `routing.ts`, and **`routing.ts` never imports anything under `failure/`**. Today nothing in `domain/src` outside `failure/` imports it except `index.ts:2`, so this adds no cycle. Keep it that way: a value cycle between these two would make `ImpossibleRouteError` `undefined` at load, depending on which file the barrel reaches first.
