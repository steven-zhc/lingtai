## Where it goes

## Markup

Build the menu from the mock in `doc/design/board-navigation.html`, inside `.menu pm`:

- When there are two or more repositories, the first entry is a lone `<Link className="tab">` that says `all projects`. Today it says `all` (`projects.tsx:75`).
- Then each repository gets one row:

  ```
  <div className="prow[ on]"><Link className="tab pname" href="/?project=…">name</Link><Link className="tab rcp" href="/recipe/…" title="what <p>'s recipe says today">recipe</Link></div>
  ```

- Port the CSS for `.prow`, `.prow.on`, `.prow .pname`, `.prow .rcp` and `.menu.pm` from the mock's `<style>` block into `globals.css` beside `.filter .menu` (`globals.css:245`). Do not port `.prow.ill`; it is the mock's own "(illustrative)" marker.

## The decision: highlight and `aria-current` follow different things

The ticket asks for two things that point different ways:
- "the row in view is highlighted"
- "the row matching `only` carries `aria-current`"

They differ with one repository. There `only` is `undefined`, but `inView` is that repository (`:42`). Today's test also says a one-project board has no `aria-current` (`projects.test.tsx:211`).

So:
- **`.on` goes on the `.prow` whose name is `inView`.** With one repository, that single row is highlighted, as in the mock.
- **`aria-current="page"` goes on the `.pname` link when `only === p`.** It marks the link whose own href is the page you are on. It does not go on the row and not on the `rcp` link.
- **On `all`, `aria-current` stays on the `all projects` link**, as today (`:74`).

## Recipe on `all`

Every row now has its own `recipe` link, so `all` shows them too. Three things argue against this and have to be rewritten, because this ticket reverses them:
- `projects.tsx:89-91`: "On `all` there is no single recipe."
- `projects.test.tsx:66-71`: "One control and not one per project".
- `projects.test.tsx:86-91`: *offers nothing on all*.

These links sit inside the menu, not on the bar row, so the-bar.md's one-chip-per-project argument does not apply to them.
