# #1469: the shape of `scripts/doc-images.ts`

## Where the code goes

`scripts/doc-images.ts` is the edge: it reads `process.env`, builds the `S3Client` (inside the store factory, never at module scope), runs one command with `Effect.runPromise` and sets `process.exitCode`. It runs its command at the top level, so **it is not importable without running**; nothing imports it, and no test does.

The logic is `apps/cli/src/doc-images.ts`, a module nothing else imports (`entry.ts` and `commands.ts` do not), so it is typechecked and unit-tested with the CLI package: `apps/cli/unit/doc-images.test.ts`, and `apps/cli/integration/doc-images-fs.test.ts` for `nodeFs.write` against a real directory. Both the object store and the filesystem are injected, so no test reaches the network.

The root needs two dev dependencies, `@aws-sdk/client-s3` and `effect` (`^4.1.2`, the packages' range), since `node scripts/doc-images.ts` imports both from the root.

## The seams

- **`plan(local, remote)`**: pure. `local` is `{ key, md5 }[]`, `remote` is `{ key, etag }[]`. It returns `upload`, `replace`, `skip`, `download` and `remoteOnlyRefused`. It has no delete member, so nothing is planned for deletion by the type, and a test asserts the keys.
  - An ETag is compared with its quotes stripped and lower-cased. One with a `-N` suffix is multipart, never equals an MD5, and plans *replace*.
- **`credentials(env)`** takes `Record<string, string | undefined>` and returns the three values (as `Redacted`) or only the missing names; an empty string is missing. It does not go through `@lingtai/env`, which reads a file.
- **`ObjectStore`** (`list(token)`, `put`, `get`, each returning a promise) comes from a `StoreFactory`. `run` wraps each call in `Effect.tryPromise`, follows continuation tokens in `listAll`, and checks credentials before the factory is called. The tests use an in-memory store with several pages.
- **`DocFs`** (`walk`, `read`, `write`) is the filesystem seam.

## Decisions

- **Downloads never overwrite.** `write` puts the bytes under a fixed-length temporary name (`.<uuid>.tmp`) beside the target and `link`s it into place, which never replaces; the temporary name is removed in every case, so a failed write leaves no partial target. Directories are made one segment at a time, and a segment that is a symlink or not a directory is refused. **A temporary name left by a process that was killed mid-write is not cleaned up**: it has no listed extension, so the walk never uploads it, and it is safe to delete by hand.
- **Remote keys pass the same filter as local paths** (`validKey`): a listed lower-case extension, `/` separators, no `.`, `..`, empty or absolute segment. A remote key that fails is never downloaded, so none can write outside `doc/`; `download` prints it as *refused* and `list` marks it *remote only (refused: not a valid key)*.
- **Keys** come from the walk, relative to `doc/` with `/` separators; symlinks are not followed.
- **MD5** is `createHash('md5')` over the bytes of `readFile`.
- **A local file that cannot be read** is reported as failed and set aside; it never stops the command. `download` only needs to know the file exists, so it neither reads it nor fetches over it. `upload` skips it, uploads the rest, and exits non-zero. `list` shows it as *local (unreadable)* and exits non-zero.
- **Errors** are printed as `<path>: <name> <code> HTTP <status>`, built from those fields and never from the SDK's own message or the error object, which can carry request headers and the access key id. Credentials are `Redacted` values and are only unwrapped to build the client.
- **Concurrency** is 4 for puts and gets. Two runs at once are harmless.
- **An unknown or missing subcommand** prints the three verbs and exits 2 before any credential is read.

## What the build sees

- `pnpm fmt` covers `apps/**`, so `apps/cli/src/doc-images.ts` is formatted; `scripts/doc-images.ts` is not, as with `cli-doc.ts`.
- `pnpm lint` runs on the whole tree.
- `pnpm images:list` with no credentials exiting non-zero is a process, so it is checked by hand; the unit claim standing in for it is the credentials test, which asserts the store factory is never called.
