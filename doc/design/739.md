## Keep `github` and add a separate variable for the command

Do not reuse the `github` boolean to decide whether the GitHub line prints. `github = true` is set in two places today:

- in the GitHub branch of `chooseFirstProject` (`init.ts:592`);
- on the re-run path with a configured App (`init.ts:620`), which prints no `next:` at all.

The ticket keeps that re-run path as it is (Edges: "prints no `next:` at all today. Unchanged"). Suppose the closing block becomes "if `github`, print the GitHub line; otherwise print the local line". The re-run path would then gain a `next: lingtai add …` line it has never had. It would also gain a `lingtai doctor --verbose` lead whenever doctor fails. No test fails when that happens: nothing in `init.test.ts` asserts the re-run path's ending today.

The shape that avoids this:

- In the GitHub branch, declare `let githubNext: string[] | null = null` beside `let github = false` (`init.ts:495`).
- The GitHub branch sets it: `['lingtai add <owner>/<repo>']` on the `gh`, `already`, `skipped` and `timedOut` paths, and `[`open ${url}/setup/repository`, 'lingtai add <owner>/<repo>']` on the `made` path. These replace the `world.log` calls at `:610` and `:618`. The line at `:617` ("the recipe is written once a repository is picked …") stays a `world.log` where it is.
- The re-run path at `:620-631` leaves `githubNext` null.
- The closing block has three outcomes:
  - `githubNext !== null`: print `next: ` followed by `[...(doctorFailed ? ['lingtai doctor --verbose'] : []), ...githubNext].join(' · ')`;
  - otherwise, `!github`: print the local line, unchanged;
  - otherwise (the re-run path): print nothing.
- Rewrite the comment at `:669`, "The GitHub paths end on their own `next:` lines above". It becomes false with this change. Say instead that the GitHub paths close here too, and that the configured-App re-run path closes on nothing.

`needBoard` stays out of the GitHub line (Out of scope, last bullet).

## `url` on the `made` path

`const url = 'url' in started ? started.url : ''` (`init.ts:609`) can only be the empty string if the board refused. A refusal returns before this line (`chosen.refused` → `boardRefused`, `init.ts:574-576`). Carry the expression over as it is, and don't add a branch for the empty case.
