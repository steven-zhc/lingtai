### 1. Claude Code is the agent, and the reviewer too: add `--reviewer claude-code`

This is the one decision the ticket does not make. `init` does **not** default the cold reviewer to the writer. It defaults to the *other* signed-in runtime: `const defaultReviewer = otherSignedIn[0] ?? writer` (`apps/cli/src/agents.ts:213`), and `--defaults` accepts that detected value (`agents.ts:229-237`). So `--agent claude-code --defaults` gives a reader who has Codex signed in a Codex reviewer, and gives everyone else a Claude Code one. The page can't truthfully say "Claude Code reviews" for both readers. The page has the same bug today in the other direction.

So the Step 1 command takes `--agent claude-code --reviewer claude-code`, and the options table gets one row for each flag. The Codex alternative is then a single line under the table, not a second command: *To use Codex instead, pass `--agent codex --reviewer codex`; it needs Codex installed and signed in.*

Change every other "Codex" in Part 1 to "Claude Code":
- the "Before you start" row (`Git; Codex installed and signed in` and its *Why* cell)
- Step 1's lead sentence ("lets Codex write the change")
- Step 3's "runs Codex"
- Step 3's image alt text ("Codex implementation")
