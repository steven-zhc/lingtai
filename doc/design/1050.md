## Watch for

- **A `Projection` literal with three methods is not a branch-holding function.** `reduce: (events, ctx) => Effect.gen(…)` inside `backlogProjection = { … }` is a property with a function-like initialiser, so `enclosing()` still answers `reduce`. Writing `reduce: Effect.fn('projector.backlog.reduce')(function* …)` makes it answer `<module>` and turns `one-reducer.test.ts` red. This is the ticket's warning, and it applies to `backlog.ts`, `spend.ts` and `ticket-report.ts`. To get the span, put `Effect.withSpan('projector.<name>.reduce')` on the `Effect.gen` the arrow returns, not `Effect.fn` on the property. `task-view.ts`'s `reduce` holds no branch itself (the branches are in `projectRunEvent`/`projectTicketEvent`), but write all four the same way so nobody copies the wrong one.
