# #1482: say "unpriced" for runs nothing could price

## Shape

This change only edits strings in the files the ticket lists. Nothing changes in events, projections, field names or JSON keys. The ticket already says which `unknown` texts stay. This note adds two things the Evidence table does not cover:

1. Five producers it leaves out.
2. Two lines where the `Done when` grep will match even though the line must not change.

## Producers missing from the Evidence table

`apps/board/src/app/report/panels.tsx` writes its own spend text inline instead of calling `moneyText`. The table only lists `panels.tsx:423`, which does go through `moneyText`. These lines count runs nothing priced, so they change too:

- `:153`: `` `… · ${spend.total.unknown} unknown${perTicket}` ``. This one prints even when the count is zero, so it will read `0 unpriced`. That matches the ticket's `+ 0 unpriced`.
- `:223`: `` `+ ${unknown} unknown` ``
- `:338`: `` `… + ${k.cost.unknown} unknown` ``
- `:713`: `` ` + ${cost.unknown} unknown` `` before `in the agent runs`

The `Done when` grep finds all five. Don't skip them because they are not in the table. `report-panels.test.tsx` is already on the ticket's list of tests to update.

Two line numbers have moved since the ticket was written:

- `apps/cli/src/conduct.ts`'s `costWords` is now at `:811-815`, not `:761-762`. Line `:814` returns `'cost unknown'` and `:815` returns `` `… + ${cost.unknown} unknown` ``.

## Lines the grep matches that must stay

`rg -n "\$\{[a-zA-Z.]+\} unknown|…" apps packages -g '!**/unit/**'` cannot reach zero, and it should not:

- `apps/board/src/lib/report.ts:223`: `` label: `${name} unknown` ``. This is a lag that could not be read; the ticket's Watch out keeps it.
- `apps/cli/src/subscribers.ts:312`: `` `subscribers: ${project} unknown, …` ``. This is not spend at all.
- Doc comments match too, e.g. `apps/site/src/lib/snapshot.ts:211`, `task.ts:1407`, `task/[id]/layout.tsx:152`, `progress.ts:541`, `landed.ts:90`, `conduct.ts:367`, `apps/cli/src/conduct.ts:811`. Rewrite the ones that quote the printed string (e.g. `` `unknown (1 run)` ``, `` `cost unknown` ``) so they quote the new string. Comments that use "unknown" as an ordinary word can stay.

The finished grep result should be only `report.ts:223`, `subscribers.ts:312`, the PR page lines the ticket excepts, and comments.

## Decisions made here

- **The `day-ceiling.ts:104` tail becomes `reported and estimated count, unpriced costs are not`.** It is the same idea as the `+ n unknown` count just before it on that line (`:102`), and both reach `lingtai status` and `lingtai doctor` through `daySpendText`.
- **Leave `unknownWhyText` (`day-ceiling.ts:110`) as it is.** Its output is a list of reasons in brackets after the count (`(a ×n, …)`), and that list never contains the word `unknown`.
- **`moneyText` exists twice: in the board (`apps/board/src/lib/report.ts:272`) and in the CLI (`apps/cli/src/report.ts:140`).** Change both. Don't merge them into one function in this ticket.
- **Edit ADR 0110 §7 in place (`doc/decisions/0110-…md:174-181`). Do not write a superseding file.** The decision itself stays the same: three parts, never `$0`. Only the word shown changes. CLAUDE.md's rule for `doc/decisions/` is *"a decision that changes is an edit to its topic's ADR"*.
  - In §7, the shown word becomes *unpriced* ("is shown as unpriced", "a count of unpriced runs").
  - The rule itself, "an unknown as unknown, never as $0", may keep *unknown* as the concept. Pick one reading and make §6 (`:162-163`, which already says *unpriced*) and §7 agree.
