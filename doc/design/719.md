## What is built, read from the code at `cc339a92`

Everything below is in `apps/cli/src/doctor.ts`. Some of it differs from what the ticket's Want row implies.

- **The default view is not "heading, sections, then a closing `next:`".**
  - It is `heading('doctor')`, then a blank line.
  - Then **the counts line comes first**, not last: `N to fix · K passed · … not checked here · … not implemented yet`, or `all K passed · …` (`:3080-3085`).
  - Then one block per thing to fix (`:3086-3093`).
  - Then the `note` lines (`:3094`).
  - Then `next: lingtai doctor --verbose`, only when something warned or failed (`:3095`).
  - In §1, write it as an exception to the general layout, scoped to doctor's default view. Don't rewrite the general rule.
- **A block is three parts:**
  - a title line: `✗ ` only for a `fail`, then the row's `title` or its `name`, then `· <areas>` in `paint.muted`;
  - the first line of the detail;
  - the `fix  …` lines from `fixLines` (`:3137-3139`).
- **What "problems first" means:** all `fail` rows, then all `warn` rows, each in area order, deferred rows left out (`toFix`, `:3151-3176`). Rows whose `fix` text is identical are drawn once, and their areas are joined into the one tag.
- **A `warn` row gets no glyph at all in the default view.** That is what "draws no `!`" means: the warning is carried by the words and by its place in the list. `!` survives only in `marker('warn')` (`:3041`), and only the `--verbose` branch calls `marker` (`:3113`).
- **`note` is not only a default-view word.** `marker('info')` returns `note` in `--verbose` too (`:3043`). So §2 should say that `note` labels an `info` row in both views, while the glyph `!` is `--verbose` only. Don't write "the default view labels info as note" as if `--verbose` did something else.
- **`--verbose` keeps the sections** through `section()` (`:3097-3132`), and its closing line is the old `N ok, … 0 failed` sentence, not the counts line above.
- **`init` prints the same flat view without the closing `next:`**, through `formatReport` (`:3179-3181`). So §1's sentence covers both "doctor's default view" and "the report `init` shows after setup". Worth half a clause.
