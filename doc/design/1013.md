## The reducer rule, written once

Put the rule in one exported predicate beside `reduceControlEvent`:

```ts
/** The setup's pause (`cause: 'setup'`), or one written before `cause` existed that holds across starts. */
export function isSetupPause(d: Record<string, unknown>): boolean
```

- Accept `cause === 'setup'`. Also accept an absent `cause` (`d['cause'] === undefined`) when `holdsAcrossStarts === true`.
- `cause: null`, an unknown string, or any other literal is **not** a setup pause. The ticket's *"a `cause` present but not `setup`"* covers this.
- Test it directly, and use it in the `ConductorPaused` case: `if (!isSetupPause(d)) return state`.

Leave out the sticky `holdsAcrossStarts` merge at `control.ts:233-235`. A person's pause can no longer land on top of a setup pause, because it reduces to nothing.

The `ConductorResumed` case (`:258-278`) becomes `{ ...state, paused: false, by: null, reason: null }`.

Leave the `DayCeilingReached` case (`:279-`) and the shutdown cases alone. They are #1003's and #999's.
