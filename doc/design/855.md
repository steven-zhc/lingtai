## Design note: #855, prose only, by hand

Hand-reword `pass` in seven documents. Most of the work is classifying each hit, and the ticket already gives the rules. This note covers the four places where a sentence on the page does not tell you which rule applies.

### 1. The stage value `pass` is a literal. Keep it

`doc/reference.md:1824-1829` lists the stages a stopped run can name, and the last one is `` `pass` ``. That is the value `conduct.ts:4805` writes: `stage: stopped?.step ?? 'pass'`, returned in `RunOnceResult`. Renaming it would mean renaming a value, and the rules forbid that.

- Keep the backticked `` `pass` `` in the list and in the sentence that introduces it.
- Re-word the prose around it: *"`pass`, where the attempt ended without landing…"*.
- Put this line in the kept list as "a stage value the code writes".

The step-ending column in `doc/writing-a-plugin.md:98-107` works the same way: `pass · hold · did-not-finish · asked · never-ran` is the verdict `pass`, so keep it. The `.html` has the same table and the same rule applies there.

### 2. Code names the document cites that have since moved

t25a and t25b have landed:

- `packages/conductor/src/` holds `run-attempt.ts` and `attempt-steps.ts`, and no longer has `pass.ts` or `pass-steps.ts`.
- `packages/domain/src/attempt-next.ts` exists.

So some citations now point at nothing:

- `doc/writing-a-plugin.md:10`: `pass-steps.ts`
- `doc/reference.md:888`: `pass-next.ts`
- `doc/reference.md:1610`: `runPass`
- `doc/reference.md:1815`: `PassResult.stoppedAt`. `PassResult` survives only in comments, at `attempt-steps.ts:122`, `:555` and `:892`. No type by that name is exported from `run-attempt.ts`. The ending type there is `AttemptEnd`, at `:1035`.

**Decision.** A citation in present tense ("is still `pass-steps.ts`'s hard-coded one", "handed to `runPass`") points the reader at code, so it gets the current name. Write `attempt-steps.ts`, `attempt-next.ts` and `runAttempt`. Use `grep` to confirm each name exists before you write it.

`PassResult.stoppedAt` has no current equivalent you can name with certainty. Re-word the sentence to name the step that stopped the attempt without naming a type, and list it as kept/unclassed in the body.

A citation stays as it was only when the sentence is about the past (*"the engine `#256` deleted"*), and then it stays in backticks.

This is still bounded to `pass`, as the ticket requires:

- `grep -w` already matches `pass-steps.ts` and `pass-next.ts`, because `-` is a word boundary.
- `runPass` and `PassResult` sit in sentences you are changing anyway.

Do not go looking for other stale identifiers. `firstPass` at `reference.md:143` has no word-boundary hit, so it is outside this ticket. Note it in the body for #856.

### 3. Attempt or turn: read the code, not the spelling

Several hits mean the loop over projects, not one try at a ticket. Each of these should become **turn**:

- `operating.md:627`, *"at the next pass completion"*: the turn reason `'completion'`.
- `operating.md:431` and `:563`, *"refuses this project for the whole pass"*: the refusal lasts one turn.
- `reference.md:89-104`, *"a pass that cannot look at a project"*: `ProjectRefused` is per turn.
- `operating.md:799` and `:1870`, *"offered again the pass after…"*.
- `operating.md:1749`: the `exhausted` row.
- `reference.md:1186`, *"the queue pass"*: `selectRunnable` runs before any attempt exists, as that same paragraph says.

The recipe hits are subtler: *"read on every pass"* (`writing-a-plugin.md:273-283`, `operating.md:134`, `:1529`). `currentRecipe` is called per project in the turn (`conduct.ts:239`, `:263`, `:661`, `:669`) and again inside the attempt. The sentence says the recipe is never cached across a restart, so **attempt** is the accurate word there. *"Every pass is refused until it restarts"* means every turn.

When a hit is ambiguous, open the cited function and decide from what it actually does. Do not settle it by asking which word reads better.

### 4. Titles, headings and link text

- The `.html` `<title>` and `<h1>` ("Change what a pass does") and the `.md`'s opening sentence ("A pass is ten steps") become *attempt*.
- The file names stay.
- A link whose target is an archived ADR keeps its target. For example, `0039-the-worktree-is-the-whole-of-a-pass.md` at `reference.md:335` stays as it is. It is a citation, and it is in the kept list as a link.
- Visible link text that says *pass* in your own words is re-worded.
- The `.html` must stay word-for-word in step with the `.md` wherever they share a sentence. Do the `.md` hunk, then its `.html` twin, together.
