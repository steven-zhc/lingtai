### The decision the ticket leaves open: the `landed` link off `/`

`Footer` is given `landed` only on `/`, and today it draws nothing for landings without it. The prop comment says *"Absent off `/`: the link to `/landed` is not drawn rather than drawn as `0 landed`"* (`footer.tsx:36`), and the test *draws no /landed link without a landed count* pins it (`footer.test.tsx`, the last case in *Footer currency line*).

That rule was about the **count**, because a missing count must not read as `0 landed`. The new `landed` link carries no number. **So draw the `landed` link on every page, and draw `<b>N</b> landed` only when `landed` is given.** This is what the ticket's *Want* asks for: three links, together at the right end, on every page with a footer.

- Change the prop comment to say this.
- Replace that test with two:
  - off `/`, the three links are there and no `landed` count is drawn;
  - on `/`, the count is text and not inside an `<a>`.
- At `the-bar.md:37-39`, *"the links to `/report` and `/spend` … on the home page the landed count links to `/landed`"* becomes: the links to `/landed`, `/report` and `/spend`, with the count on the home page as plain text.
