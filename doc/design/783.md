## Shape for #783

**Where it goes.** `loadSdk` in `apps/board/src/lib/telemetry.ts:16-20` gets a fourth key, `resources: await import('@opentelemetry/resources')`. `installTracing` (`telemetry.ts:62`) then passes `resource: sdk.resources.resourceFromAttributes({ 'service.name': SCOPE })` to the provider.
- Use `SCOPE` (`telemetry.ts:13`) itself, not a second constant with the same value. Its doc comment can say it is now the service name as well as the scope `OnlyScope` keeps.
- Import nothing from `@opentelemetry/resources` at the top of the file, not even `import type`. Write the type in a `ReturnType<typeof loadSdk>` style if you need one. The only top-level SDK import today is `import type` from `sdk-trace-base` (`telemetry.ts:3`), and that should stay the only one.

**Why the provider will not bring the path back.** The ticket leaves open whether the SDK merges a given resource with its default. In the installed 2.12.0 it does not:
- `sdk-trace-base` is now a shim over `@opentelemetry/sdk-trace`.
- That package's `build/src/TracerProvider.js:34` reads `this._resource = options.resource ?? (0, resources_1.defaultResource)();`. The default is used only when none is given.
- `defaultResource()` (`resources/build/src/ResourceImpl.js:109-116`) is where `service.name = unknown_service:<argv0>` comes from (`default-service-name.js:17-18`). Passing a resource skips it completely.

So the exported resource is `{ 'service.name': 'lingtai-board' }` and nothing else. The `telemetry.sdk.*` attributes the default carries are dropped too. That is the intended result: nothing in Want asks for them, and fewer attributes leave the machine.
- Do not write `defaultResource().merge(...)` "to keep the SDK attributes". It adds a call that can bring a default back if it is ever written in the wrong order.
- The Done-when test (no resource value contains `/`) is what holds this if a later SDK version starts merging.

**The test.** Add it to `apps/board/unit/telemetry.test.ts`, written the same way as *exports lingtai-board spans and drops every other scope* (`:39-49`):
- Install with `on`, `none` and an `InMemorySpanExporter`, end one `lingtai-board` span, then `forceFlush`.
- Assert `span.resource.attributes['service.name'] === 'lingtai-board'`.
- Assert `Object.values(span.resource.attributes)` has no string containing `/`.

The module-loading case at `:18` gets renamed to four modules and checks `typeof sdk.resources.resourceFromAttributes === 'function'`. The no-endpoint case at `:25` needs no change, because `installTracing` returns at `:60` before `loadSdk`.
