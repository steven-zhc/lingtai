## The scripted commit

1. **Identifiers and file moves by language service** (ts-morph or tsserver rename, `moveToFile`/file rename with imports updated), not `sed`. The rename then:
   - leaves strings, test titles and keys alone by construction;
   - writes the `liveRunWorld` shorthand as `tallyPass: tallyTurn` correctly, which a word `sed` cannot do.
2. **Then, in the same commit, a word replacement over comment lines only.** That means lines whose first non-blank characters are `*`, `/**` or `//`, in `packages apps scripts`. It covers the exact old names and the old file names, so comments follow the rename the way `dd518075` did for #849. This is still *"a scripted rename of identifiers and words"*.
   - Match file names with `(?<![\w-])` in front (perl). Otherwise `pass.test.ts` matches inside `conduct-a-whole-pass.test.ts` and `trace-a-pass.test.ts`, and `pass.ts` matches inside `one-pass.ts`.
   - Replace longest first.
   - Do not touch `doc/decisions-archive/` (append-only) or `CLAUDE.md` (the operator's).
3. **The file moves:**
   - `src/pass.ts` → `run-attempt.ts`
   - `src/pass-steps.ts` → `attempt-steps.ts`
   - `test/one-pass.ts` → `one-attempt.ts` (26 importers; none of its exports carry the word)
   - the seven `unit/` test files the ticket lists
4. Run `pnpm fmt`. If `packages/domain/unit/events-json.test.ts` goes red, also run `pnpm events:generate` (`package.json:31`). `doc/events.json:421`'s permalink is pinned to commit `674a9f8`, so it may not move at all.

Do not add compatibility aliases in `index.ts`. Every importer is in this monorepo.
