# Design note: #849, domain's attempt names

The ticket covers the names. This note covers what it leaves out: three things that turn the gate red on their own after a file move, one tool it names that does not exist, and four calls about names the ticket does not list.

## The scratchpad script does not exist

The ticket says to start with `python3 -I scratchpad/ids.py`, but this worktree has no `scratchpad/` directory. Use this grep instead. It finds the in-scope names and anything that contains them:

    grep -rhoE '\b[A-Za-z_]*(RunState|emptyRun|RunLifecycle|RunStatus|reduceRun|PASS_STREAM_PREFIX|passStream|isPassStream|passIdOf|PassNext|RunRef|PassObservation|passTransition|aRun|RunFixture)[A-Za-z_]*\b' \
      --include='*.ts' --include='*.tsx' packages apps scripts --exclude-dir=node_modules | sort | uniq -c

Today it also returns some longer tokens that contain an in-scope name. A word-boundary `sed` leaves them alone, and they stay as they are:
- `RunRefsPublished` (an event)
- `aRunStarted`, `aRunSpent` and `aRunFailure` (they spell events)
- `quotaRuntime`
- `DomainRunState`

## Three things a file move breaks, and they go in the scripted commit

The scripted commit has to be green on its own (CLAUDE.md *Commits*), so all three go in with the moves.

1. **`packages/domain/unit/histories.test.ts:88`**: `caseLabels('run.ts', 'reduceRunEvent')` opens the file by name with `readFileSync(src(file))` (`:38`). The `sed` renames the function argument but not `'run.ts'`, so the test can't find the file. Change it to `caseLabels('attempt.ts', 'reduceAttemptEvent')`. Leave `COVERS.run` alone: it is the histories' group key, and the ticket keeps it.
2. **`doc/reference.md:1023`**: the retired-names ledger has the row `| packages/domain/src/pass-next.ts | work-item ×2 |`. `packages/domain/unit/retired-names.test.ts` reads that table, and *"a count with nothing behind it is as red as one that is short"*. After the move, the old row points at nothing and the new file's two uses are unrecorded, so it fails both ways. Change the row's path to `packages/domain/src/attempt-next.ts` and keep the count at ×2. The test sorts what it finds (`:245`, `:249`), so put the row where it sorts, after `apps/…` and before `packages/domain/src/envelope.ts`. The number of rows does not change, so the sentence that counts them stays as it is.
3. **`packages/domain/src/index.ts`**: change the two lines `export * from './pass-next.ts'` and `export * from './run.ts'` to point at the new files. No alias lines.

Do **not** run `sed` over the text `run.ts`. Many comments say `run.ts` and mean `apps/cli/src/run.ts`, which is not being moved (for example `packages/daemon/src/converge.ts:106` and `packages/conductor/src/ownerless.ts:5`).

## Names in scope by meaning but not listed in the ticket

The rule says to class every exported name by reading its definition. These are my calls:

- **`run-codec.ts`: `encodeRun`, `decodeRun`, `RunCodecError` (`packages/domain/src/run-codec.ts:110`, `:115`, `:123`). Keep them.** They encode the attempt state, so by meaning they belong to this ticket. But `RunCodecError` has `override readonly name = 'RunCodecError'`, and `decodeRun`'s refusal says *"the stored run state is not today's shape"*. Both are string values that reach error output, and changing strings belongs to the strings tickets (t25d (#852) and t25e (#853)). The ticket's file list is also closed at `attempt.ts` and `attempt-next.ts`. So the codec keeps its names and its file, and only its `import type { RunState } from './run.ts'` changes. List all four in the hand commit's body as *kept, an attempt name left for the codec's own rename because its error name is a string value*.
- **`apps/board/src/lib/task.ts:29`, `type RunState as DomainRunState`.** The `sed` makes it `AttemptState as DomainRunState`. The alias is the board's own local name, and the board's names are t25c (#851)'s. Leave it and list it.
- **`nextOf(outcome, run: RunRef)` (`pass-next.ts:115`).** Only the type becomes `AttemptRef`. The parameter `run` stays, because `nextOf` is not a function this ticket renames.
- **Domain's own test files follow the files they test:** `packages/domain/unit/run.test.ts` becomes `attempt.test.ts`, and `pass-next.test.ts` becomes `attempt-next.test.ts`, as file moves in the scripted commit. `run-codec.test.ts` stays with `run-codec.ts`. `run-spent.test.ts` tests the `RunSpent` event and stays.
