# Design note: #1270, the person's moves and the report get their new words

## What changes and what stays

**Change only the strings a person reads. Leave every identifier alone.** That covers JSX text, `title`/`aria-label`/`label` values, consequence sentences, CLI help and output lines, and error sentences the server returns that the board shows as they are (`decide.tsx:722`). Do not touch:

- `fixRounds` in `packages/conductor/src/report.ts:25,76,152,404`. It is a key in `lingtai report --json`, and that output is a contract.
- `sortBy: 'rounds'` (`report.ts:190`).
- `RoundBucket`.
- The `Recommended` value `'requeue'` (`decide.tsx:49`) and the matching `action: 'requeue'` in `packages/domain/src/wait-words.ts:159`.
- The components and server actions `Requeue`, `EditBodyAndRequeue`, `RerunStepButton`, `requeueCard`, `rerunStepCard` (`decide.tsx:29-31,328,375,479`).
- `standing.rerunWork`.
- Code comments, including `#431 fix round` in `apps/cli/src/recipe-flow.ts:69`.

There are three reasons:

1. The ticket says *words only*.
2. #1242 was split because one diff reached 438 KB against the reviewer's 400 KB budget (0108 §14). A rename of identifiers would push this diff back toward that size.
3. Because no figure-producing code changes, *every number on `/report` is the same* holds by construction, not by argument.

## The map

Apply these four words everywhere a string uses them:

| Old word | Sense | New wording |
|---|---|---|
| *fix round(s)* | Both the person's `FixRefusal` and the machine's own round | *refusal fix(es)*, or *fix the refusal* as a verb. This matches `runtime.limits.attempt.refusalFixes`. |
| *requeue* | | *start a new attempt*. Where you say what happened, the attempt is **queued**, not started: `EditBodyAndStartNewAttempt` already says *queue a new attempt* (`apps/board/src/lib/resolution-copy.ts:31`), and every new sentence must be as truthful. |
| *rerun (this step)* | | *redo this step*. The pending label `'rerunning…'` (`decide.tsx:366`) becomes `'redoing…'`. |
| *restart* | The **machine's automatic new attempt** | *new attempt*, bounded by `runtime.limits.ticket.newAttempts`. `NO_RESTART_EFFECT` (`resolution-copy.ts:4`) becomes a sentence like *This neither spends nor refunds one of the ticket's automatic new attempts.* Keep the constant's name. |

The machine's round is renamed too, not just the person's. Done-when says *fix round(s) appears on no board page, in no CLI output*. Some hits are the machine's:

- the chip `` `fix round ${head.round}` `` at `apps/board/src/app/standing.tsx:271`
- the triage sentence at `standing.tsx:582`
- `'a fix round reads at most'` at `apps/board/src/lib/recipe-lines.ts:124`
- `wait-words.ts:174,310`

## The trap: one word, two meanings

**`restart` also names the daemon's restart, which this ticket must not touch.** Leave these alone:

- `lingtai restart` at `apps/board/src/app/health.tsx:66,89`
- the copy at `apps/board/src/app/setup/github-app/page.tsx:22-43,211-216`
- the restart lines in `CLAUDE.md`

A blanket sed on `restart` breaks the health dot's remedy command. Go through each hit by hand.

Treat *requeue* the same way. `wait-words.ts:162,164` says *requeued as written, it buys another run*. That is a person's move, so it becomes *started again as written* or similar. Keep its `action: 'requeue'` key.
