### The decision the ticket leaves implicit: Report and Lingtai are not objects in the count

The ticket's **Want** lists the bar as *Lingtai, the filter, health and Report*. That list leaves out the headline, which is still drawn. Do not copy it. The code names the counted objects as **filter, health, headline**, in that string: twice in `page.tsx` (`:84-86` and `:789-795`) and once in `projects.tsx:4`. `apps/board/unit/projects.test.tsx:24-42` holds the code to that set. No test reads the-bar.md (`git grep` for `design/the-bar` in `apps/board/unit` finds only a comment at `bar.test.ts:7`). So the doc can drift silently, and it has to name the same three objects in the same words.

The current shape to write:

- **The bar is a frame and a row.** The frame is the same on every page: `Lingtai` (home) at the left and `Report` at the right. The row is the page's own objects. On `/` those are the filter, health and the headline. *A chip is not free, and the row is the unit* still governs the row. Say plainly that the frame does not grow either: a second destination beside Report has to be argued here, the way a fourth object does.
- **Why Report is in the frame.** It is the operator's choice of 2026-11-06. The report is the one page a person goes to on purpose. Everything else is either glanced at (the bar, the footer) or reached from the thing it is about (a card opens its task, the Landed count opens `/landed`, a repository's row opens its recipe). A link to a page you visit on purpose is not a reading. That is why it is on the bar and not in the footer, which carries none.
- **Why the home moved to the footer.** Keep #767's reason: two homes were told apart by remembering which terminal was which, so the home is shown and never assumed. Then add #947's reason. Once `Lingtai` became the link home on every bar, the brand is a control. The home is a fact that never changes while the page is open, and that is the definition of a reading, so it goes where the reading is. It is the footer's last item, and the prop is required so no page can drop it.
