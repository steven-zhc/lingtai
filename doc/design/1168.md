**Use `overflow-wrap: anywhere`, not `break-word`.** This is the one choice that is easy to get wrong. The pill is a flex item in `.meta`, which is `display: flex; flex-wrap: wrap` (`globals.css:531`). Such an item has `min-width: auto`, so it can't shrink below its min-content width. `break-word` breaks a long word only at layout time and leaves the min-content width unchanged. `anywhere` also lowers the min-content width, so the item can shrink. With `white-space: normal` the sentence's min-content width is its longest word, so either value works for this sentence. `anywhere` also keeps a long unbroken token (a runtime name, a date with no spaces) inside the card. Keep `max-width: 100%` so the pill never asks for more than the `.meta` row's width.
