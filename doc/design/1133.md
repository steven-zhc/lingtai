## The case the ticket's three rules miss: a production caller that is not a host

Many faces here are called from `apps/cli/src` or from another `src` file in the same package. For example:

- `apps/cli/src/daemon.ts:499`: `Effect.promise(() => projectFilters(registered))`
- `packages/daemon/src/daemon.ts:199`: `Effect.promise(… controlWatermark())`
- `packages/conductor/src/repository-list.ts:25`: `Effect.tryPromise({ try: () => loadAllProjects() })`
- `packages/conductor/src/schedule.ts:279`: `Effect.promise(() => readFixFiles(…))`
- `apps/cli/src/project-pause.ts:118`: `readControl`, called the same way

**Rule: for a face you are deleting, move each of these callers to the face's own body, the Effect in its `return Effect.runPromise(<call>)`.** This is the rule #1118's note set out, and attempt-1 applied it.

- `Effect.promise` / `tryPromise` around the face becomes `yield* twin(…)`.
- If the caller's error type was `Error`, add `Effect.mapError` with the conversion its `catch` used.
- `typeof ticketsFor` seam types become the `ticketsOfSeam` / `…Effect` types. Attempt-1's `filter.ts`, `ownerless.ts` and `converge.ts` already do this.

**For a face you are keeping, leave its non-host callers alone.** Examples: `apps/cli/src/status.ts:405` calling `projectFilter`, and `account.ts:113` calling `currentRecipe`. The ticket only asks that the `why` name the host callers. Moving them is right, but it is diff this ticket cannot afford (see below).

Apps/cli is counted at `{async: 0, run: 0}` (`effect-ratchet.baseline.json:2`). A move that wraps a twin in `Effect.runPromise` turns it red. Never "fix" that in the baseline.

### Two faces the rule cannot move inside this ticket

**`beaconBeatFace`** (`packages/daemon/src/control.ts:644`):

- Its only caller is the promise chain in `startBeaconOn` (`:651-690`). That is a synchronous function driven by `setInterval`, with no fiber context to run under.
- `runPromiseWith(Context.empty())` is counted (#1115).
- Moving it means rebuilding the daemon's heartbeat as a fiber, a liveness change that does not belong in a delete-or-keep pass.

**`refreshOnce`** (`packages/conductor/src/rate-snapshot.ts:140`):

- `refreshRates` (`:124`) dedupes a promise.
- `apps/cli/src/daemon.ts:780` calls it through `startRates` from a bare `setInterval`.
- `ratesSettled` (`:132`) hands that promise to the lock release (`daemon.ts:255`, `:840`; `run.ts:706`).

**Decision: keep both, with `until: "#1118"` and attempt-1's `why` text.**

- Not `#790`: #1134 adds the assertion that fails on any `#790`, and its scope does not include these packages.
- Not `0101 §7`: the caller is not a host.
- The PR body must name these two as the faces still owed a ticket of their own, so a person can retarget the `until`.
- Do not open an issue from the pass.

## Keep the diff under the reviewer's limit

#1118 was split because its diff was 439,570 characters and the `review` step reads 400,000 (#1118's last comment). The review never ran.

Attempt-1's diff for just `packages/conductor` and `packages/daemon` is 256,760 characters, and `apps/cli` adds 63,737 more. Most of that is call sites inlined in tests and then rewrapped by `oxfmt`:

- `run-attempt.test.ts`: 791 lines;
- `resolve-wait.test.ts`: 607 lines;
- together, 73 KB.

**Decision: a deleted face whose callers are tests moves into a test helper. The call sites stay byte-identical.**

- Add `packages/conductor/test/promise-faces.ts`, the counterpart of attempt-1's `packages/daemon/test/promise-faces.ts`. Take that daemon file as it is.
- Put `runAttempt` and `claimStep` there, each one line: `Effect.runPromise(runAttemptEffect(attemptPortsFrom(options)))`, the body `run-attempt.ts:1993-1994` and `:2019-2020` has today. Add any other test-only conductor face the same way.
- Each test file's diff is then its import line.
- `test/` is outside the count, which scans `<pkg>/src` only (`effect-ratchet.test.ts:446-463`).
- This is what "move the tests to the Effect, no assertion changed" asks for, and a reviewer can check it at a glance.

Where attempt-1 already inlined a small file cleanly, you may keep its version. Do not take its `run-attempt.test.ts`, `resolve-wait.test.ts`, `triage-answers-written.test.ts` or `attempt-steps.test.ts` rewrites; use the helper for those.

`git diff HEAD | wc -c` should be well under 400,000 before you commit. Say the figure in the PR body.

## Edges

- **A read that fails through a moved caller:**
  - Where the old wrapper was `Effect.promise`, a rejection was already a defect, so nothing changes.
  - Where it was `tryPromise`, a typed failure stays typed through `mapError`. A defect now stays a defect. Do not add `catchAllDefect` to preserve the old behaviour (as in #1117).
- **Shutdown and interruption:** the moved callers no longer start a root fiber, so a drain's interrupt reaches the twin. The beacon and the rate refresh are unchanged because they are kept.
- **Two passes at once, retries, a stale page:** these do not apply. No event and no projection changes.
- **Cost to later tickets:**
  - The two `#1118` entries need a ticket.
  - A face kept for a board test goes red the day that test is deleted.
  - A kept face still has `apps/cli` callers that should move one day; that is not this ticket.
