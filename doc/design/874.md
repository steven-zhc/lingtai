## Shape

The change touches three files. Nothing else should need to move.

**`packages/domain/src/control.ts`.**
- Add `pausedAt: number | null` to `ControlState` and to `emptyControl` (`:145`).
- `ConductorPaused` (`:166`) sets `pausedAt: e.version`.
- `ConductorResumed` (`:216`) clears it to `null`, alongside the other pause fields it already clears.
- `evaluateControl`'s expiry branch (`:292-301`) also sets it to `null`.
- Raise `version: 1` to `2` (`:331`).
- Put `scopeControl(state, since)` beside `evaluateControl`. It is a pure function and reads no clock. `index.ts:23` re-exports everything from `control.ts`, so no export needs adding.

**`packages/domain/src/control-codec.ts`.** Add `pausedAt: z.number().nullable()` to `StoredControl` (`:17`). Make it required, not `.optional()`: the codec "refuses by name rather than filled from `emptyControl`" (`:4-7`). Version 2's key never asks for a version 1 string anyway, so a stored state without the field is an error.

**`packages/daemon/src/control.ts:142-160`.**
- Lift the existing `readThroughSnapshot` + `Either` + `evaluateControl` block into one local helper. Both paths call it: `since <= 0` returns its result, and `since > 0` returns `scopeControl(helper(), since)`.
- Pass `snapshots` and `cache.writer` exactly as the `since <= 0` path does now, including the rule at `:140-141` that a store passed in has no default snapshots.
- The daemon's three callers pass no `cache` (`apps/cli/src/daemon.ts:542,569,647`). So `writer` is `undefined` there, and `snapshot-read.ts:83` offers nothing. That is how the daemon stays out of writing snapshots, which is out of scope, with no new code.
- `reduceControl` may then be unused in this file. Delete the import or `pnpm lint` will fail.
- Rewrite the doc comment's last paragraph (`:121-132`, *"The scoped reduce is read first…"*). It should say that the answer is the whole-stream state scoped by version, and that `requested`, `continuing`, `discussions`, `holdsAcrossStarts`, `ceilingWaivedUntil` and `pausedAt` are the whole stream's values, which no caller with `since > 0` reads.

## `scopeControl`, exactly

```
pause kept   ⇔ state.holdsAcrossStarts || (state.pausedAt !== null && state.pausedAt > since)
pause clear  → paused false; by, reason, until, cause, pausedAt null
               (holdsAcrossStarts is already false, or the pause would have been kept)
shutdown     → kept iff state.shutdown !== null && state.shutdown.version > since, else null
```

Return the argument itself when there is nothing to clear. That makes `scopeControl(s, 0)` be `s`, not just equal to it, because every version is at least 1.

The equivalence holds because the reference's `whole` is already `evaluateControl(reduceAll(all), now)`, and that is exactly the state the new path scopes. The only part of the reference being replaced is the scoped reduce. When the newest pause-or-resume is a pause after `since`, the scoped reduce saw that same `ConductorPaused`, so `by`, `reason`, `until` and `cause` are the same, and expiry is decided against the same `until`. The `holdsAcrossStarts` merge (`:184`) copies those four fields from `whole`, and keeping them is the same thing. The shutdown cases (a withdrawal naming an older request, a request hidden by a newer one, a resume that clears both) all come down to "the reducer's standing request, by its own version". `ConductorShutdownWithdrawn` only acts when `state.shutdown.version === d.version` (`:205`).

## The test

The clock is the decision the ticket leaves open. `readControl` has no `now`, and calls `new Date()` itself (`daemon/src/control.ts:153`). Do not add a `now` parameter to it. That would be a signature change for one test.

Put the matrix in `packages/daemon/unit/control-snapshot.test.ts`, as a second `describe` that reuses `build` and `all` from that file:
- Keep the reference as a local function in the test, copied verbatim from `:179-184` with the `now` made explicit: `reduceControl(…, now)` twice.
- For each `now`, call `vi.useFakeTimers({ toFake: ['Date'] })` and `vi.setSystemTime(now)`. Faking only `Date` keeps the memory store's promises and Effect's scheduler real. Faking timers too can hang `runPromise`.
- Restore the timers in `afterEach`.
- The `now` values: take every distinct parsed `until` in the history, and use one instant a millisecond before it and one a millisecond after. Add one fixed instant for histories that have no `until`.
- Compare the six contract fields through a `pick`, never `toEqual` on the whole state. `pausedAt`, `holdsAcrossStarts` and the queues are meant to differ.
- Run every `since` from 0 to `len`. Then repeat with `snapshots.plant(at(k))` for each `k` from 1 to `len`. `key` in that file already reads `controlReducer.version`, so the planted snapshots are version 2's.
- A history that is long enough multiplies quickly (prefixes × since × now × plants). If the run is slow, keep every combination but put each prefix in one `it`, as the existing `describe` does.

Add `scopeControl`'s own cases in `packages/domain/unit/control.test.ts`:
- `since = 0` gives back the same object;
- `pausedAt === since` is cleared (the boundary is strict);
- `holdsAcrossStarts` is kept below the watermark;
- a shutdown below `since` is cleared while a pause above it is kept.

Also check that `ConductorPaused` sets `pausedAt` and that resume and expiry clear it.

## What goes red, and how to fix each

- `packages/domain/unit/reducers.test.ts:61`: the failure message prints the new hash. Add it as `"2"` in `reducer-versions.json` and leave `"1"` byte for byte. `histories.hashes.json` hashes the input events (`histories.test.ts:175-176`), so it does not change and must not be edited.
- `packages/domain/unit/control-codec.test.ts` may decode a literal stored JSON string. A string without `pausedAt` is now refused, so add the field to the literal rather than loosening the schema.
- `packages/daemon/unit/control-since.test.ts` must stay green unchanged. It is the #405 behaviour stated in plain cases, and the matrix does not replace it.
- `tsc` finds each `ControlState` literal. Every one is `pausedAt: null` unless it describes a standing pause, and then it is that pause's version.

All of this is unit-level: memory store, memory snapshot store, fake `Date`. Nothing here depends on `pnpm test:integration`. `packages/daemon/test/contract.ts:321` (the integration contract's watermark case) should keep passing for the same reason the matrix does, but it is not the check to wait for.
