# Design note: #1289, `/report` says each thing once

## The decision the ticket does not spell out: rename at the source, in the conductor

The Fix row lists only board files. But part of the text on the page is not written in the board:

- **The sentence at the top of each ticket in the list.** It is `TopTicket.sentence`, built by `sentenceOf` in `packages/conductor/src/report.ts:442-455`. Its wording is ``${head} over ${plural(t.fixRounds, 'refusal fix', 'refusal fixes')}``, and `head` takes its purpose name from `PURPOSE_WORDS` (`:451`).
- **The purpose line and each wait line.** `panels.tsx:420` and `:426-427` build them from `purposeWords`, `reasonWords` and `resolutionWords`. Those read the tables at `report.ts:381-419`, which include:
  - `Answering: 'answering refusals'`
  - `ProposedEscalated: 'a decision after its refusal fixes ran out'`
  - `FixRefusal: 'a refusal fix granted'`

The mock shows all of these already reworded: *"63% fixing review findings over 12 fix rounds"*, *"a decision after its fix rounds ran out"*, *"a fix round granted"*. Done-when also says no *refusal fixes* may be left on the page. Renaming only `PURPOSE_SERIES` would leave them there.

So edit the conductor's tables and `sentenceOf`, and do not reword anything in the board. 0123 requires this. In the ADR's own words (`doc/decisions/0123-the-report-counts-what-the-log-holds.md:209-212`):

> "The board's `/report` page and `lingtai report` aggregate its rows … the aggregation, §3's figures and §4's sentence are one pure function both call."

A board-side rewrite of the sentence would split it into two templates. The changes in `report.ts`:

- `PURPOSE_WORDS`:
  - `Work` → `building`
  - `Answering` → `fixing review findings`
  - `Judge` → `AI judge`
  - `Triage` and `Discussion` keep their own words. The per-ticket line shows them separately; only the chart's `PURPOSE_SERIES` merges them as *triage*.
- `REASON_WORDS.ProposedEscalated` → `a decision after its fix rounds ran out`
- `RESOLUTION_WORDS.FixRefusal` → `a fix round granted`
- `sentenceOf` → `plural(t.fixRounds, 'fix round')`

**What this costs:** `lingtai report` changes its words too. `apps/cli/src/report.ts:22-24` and `:254-262` read the same functions. Keep the CLI's own labels in step with them so the command does not mix two vocabularies — for example the heading `cli/unit/report.test.ts:295-308` asserts (*most refusal fixes* → *most fix rounds*) and `median refusal fixes` (`:270`). That is words only.

`apps/site/scripts/take-books.ts:169` reads only `PURPOSE_WORDS`' keys and order, so its counts are unaffected. Leave `CAUSE_WORDS` alone.

These conductor tests hard-code the old words and change once:

- `packages/conductor/unit/report.test.ts:374-403`
- `apps/cli/unit/report.test.ts:250`, `:270`, `:290`, `:295-308`
- `apps/board/unit/report-panels.test.tsx:57-78`, `:233-239`, `:341`, `:357`

Change no figures.

The *handled for you* panel does not use any of these tables. Its copy lives in `apps/board/src/lib/handled.ts` and `handled-today.ts`. So this change leaves #1285 and #1288 untouched. Do not edit those files.

## The board

### `page.tsx:141-183`
Put every panel in one `rp-grid`, in the order and with the titles and subtitles of the ticket's table:

1. Fix rounds per landed ticket, then Reviews needed to pass
2. Spend (`wide`)

4. Tickets that took the most work
5. Why work stopped for a person (`wide`)

The grid and panel markup should match the mock's markup (`doc/design/report-cleanup.html`, the `rp-grid` section). Delete the `CostliestPanel` import, the `<Panel>` at `:165-166`, `CostliestPanel` itself (`panels.tsx:240-272`) and its test (`report-panels.test.tsx:357`). `report.costliest` stays computed: `report()` is out of scope.

### Spend panel
`WhereItWentPanel` (`panels.tsx:188`) becomes the *by purpose* half and `SpendPanel` (`charts.tsx:199`) the *each day* half. Put both inside one `<Panel title="Spend" wide>`, each under a small heading. Both already colour from `PURPOSE_SERIES`, so the same purpose gets the same colour in both halves without extra work.

`purposeRows` (`panels.tsx:86-97`) and the `total` it sums (`:190`) stay the donut's source. That is the same figure the bar divides by today, so the centre total and every percentage are unchanged.

### Donut geometry
Write it as a pure function next to the other geometry in `apps/board/src/lib/report.ts` (from `:339`), so `HOME=/nonexistent pnpm test` can test it without rendering. It takes the rows and returns one path per non-zero segment. Each series gets a reported segment and then an estimated one, in `PURPOSE_SERIES` order, starting at 12 o'clock and going clockwise. Use the mock's sizes: 180-unit box, outer radius 70, inner radius 46, estimated segments at opacity .45.

**The trap is a single segment that is the whole ring.** It happens whenever everything is one purpose and all reported, or all estimated. An SVG arc from a point back to itself draws nothing. So emit a full-ring segment as two half-arcs, and test that case by name. Leave zero-width segments out entirely rather than drawing a degenerate path.

The empty cases:
- `total === 0` with only unknown-cost rows: draw no ring and keep the rows. Today's bar already does this (`:196-198`).
- `rows.length === 0`: keep today's `Empty` line (`:191`).

The centre shows `dollars(total)`, plus `+ n unknown` when any row has unknown runs. The `sw-rows` list stays as the legend beside the ring.

### `TopPanel` (`panels.tsx:385`)
- Tabs: *by rounds* → **most fix rounds**, *by cost* → **most spend**. Keep the `sort` values `rounds` and `cost`, so `/report?sort=cost` and `reportHref` (`report-lib.test.ts:62`, `:88`) do not change.
- Column headers: *kind* → **type**, *refusal fixes* → **fix rounds** (`:402-405`).
- Each ticket's `t.sentence` stays visible. The purpose line and the wait lines (`:417-430`) move inside a `<details>`. Its `<summary>` reads `{n} more line(s) — where the money went and each wait`, where *n* is the number of lines folded. Render no `<details>` when *n* is 0.
- The tile's `title` at `panels.tsx:163-167` still says *answering a refusal*; reword it as well.

### `KindsPanel`
Remove the *spent in the window* `<th>` (`:363`) and `<td>` (`:378`). The first header becomes **type**, as in the mock.

### Charts and tiles
- `RoundsPanel` (`charts.tsx:169-180`): both its `label` and its per-column `<title>` say fix round(s).
- Tiles: `panels.tsx:130` and `:167` get the ticket's new keys.
