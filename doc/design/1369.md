- `packages/recipe/src/settings.ts:435`: *"level it is `source.assignee`, beside the other three (#1356)"*.

The paragraph above it (`:1314-1318`, *"`runtime.assignee` is now the recipe's own v1 spelling"*) has the same problem. Keep its history clause (#373 moved the key out of the machine file). End it on the current spelling, and point out that every reader still asks `assigneeOf`. That is why #1356 changed no callers.

`:1337-1338` contains `assignee: { take: both }` … *"what an absent `runtime.assignee` has always selected"*. `both` is now an old spelling too (`resolve.ts:395` rewrites it), so this becomes `take: all` and *"an absent `source.assignee`"*.
