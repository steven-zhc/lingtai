## The rule, in `count()`

- **Where it looks.** Today `visit` drops any `*With` property through `RUN` (`effect-ratchet.test.ts:70`). Keep `RUN` as it is, and add `RUN_WITH = /^run[A-Z]\w*With$/`. When a property access on an `effects` name matches `RUN_WITH`, look at its parent:
  - If the parent is a `CallExpression` with the access as its callee, it is counted when `arguments[0]` is an empty context.
  - The curried form `Effect.runPromiseWith(Context.empty())(e)` is covered, because the inner call is the one inspected.
  - Record the hit at the property access, as today, so `pos`/`line` match the existing hits.

  Also handle bare named imports of `run*With` from `effect/Effect`. `importsOf` (`:105`) only puts names matching `RUN` into `bare`, so keep a second map for the `*With` names.
- **What counts as an empty context.**
  - First unwrap `ParenthesizedExpression`, `AsExpression`, `SatisfiesExpression`, `NonNullExpression` and `TypeAssertion`.
  - It is then a call `X.empty()` or `X.make(…)`, where `X` is `Context` imported from `'effect'` or a namespace or default import of `'effect/Context'`. Extend `importsOf` the same way it already finds `Effect`.
  - Or it is an identifier with a top-level or nested `const` declaration of that name in the same file whose initializer, unwrapped, is such a call. Shadowing is ignored: a false positive there is a rename, not a hidden run.
- **Across files.** `count(name, text)` keeps its signature for the existing tests and takes an optional third argument: the empty-context names exported by every counted file. The test's walk builds it in a first pass, with an exported `const` whose initializer is an empty context, plus `export { x }` of such a `const`. Resolution:
  - A relative specifier is resolved against the importer's directory.
  - An `@lingtai/<pkg>` or `@lingtai/<pkg>/<sub>` specifier matches if *any* counted file under that package's `src/` exports the name as an empty context. This trades exactness for not walking `package.json` `exports` and `index.ts` re-exports.
  - No such export exists today. The unit case builds one: two files, and the third argument.
- **Not counted.** An argument that is an identifier with no `const` initializer: a parameter, `ports.services` (`apps/cli/src/daemon.ts:226`), or a `let`. Also anything bound from `yield* Effect.context()`, directly or under a ternary. `schedule.ts:179` reads `const runtime = options.slots ? yield* Effect.context<Repo | AgentHost>() : undefined`, and `:295` runs `runtime!`. The unit cases are the ticket's list plus the `let` case above.
- **Doc comments.** Rewrite `RUN`'s doc comment (`:63-69`) to say that a `*With` run is counted when its context is empty, and why.
