## The prop and the call site

`Outgoing` takes `folded?: boolean`, defaulting to `false`. The default keeps every existing caller and every existing `outgoing.test.tsx` case byte-identical, so the second Done-when box holds without anyone touching it.

## "Pressing Edit opens it": the `<details>` is controlled

An uncontrolled `<details>` can't be opened from the Edit button. A bare `open={x}` without `onToggle` gets reset by React on the next render, which undoes a person's click. So:

- `const [open, setOpen] = useState(!folded)`
- `<details open={open} onToggle={(e) => setOpen(e.currentTarget.open)}>`
- The Edit / Change-the-edit `onClick` (`:158`) also calls `setOpen(true)`.

`renderToStaticMarkup` drops `open` when it is `false`. That gives the Done-when assertion directly: `<details` is present, `<details open` is not, and `<summary>` contains `bytes`. When the edit succeeds and the page recomposes, `draft` resets as today (`:85`) and `open` stays whatever it is, so the person goes on looking at the text they just changed. Opening is local state, and nothing persists it.
