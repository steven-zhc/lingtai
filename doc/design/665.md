### A trap the ticket does not mention

Do not suggest `~/.lingtai` as a path to deny. It is the obvious one, since `~/.lingtai/config.yml` is the file the README's *Not contained* names. But the agent's own worktree is `~/.lingtai/worktrees/<project>/<runId>`, and its commits go into `~/.lingtai/repos/<project>.git`, according to the tree in `doc/operating.md:29-38`. Denying the whole directory stops the agent from reading its own work.

If the README names example paths at all, name `~/.lingtai/config.yml` and `~/.ssh`. Say that this was not measured, because #664 only measured a throwaway directory. Otherwise just keep *the ones you want closed*.
