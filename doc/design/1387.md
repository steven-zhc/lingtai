### Why the rules go to `reference.md`, not `plugins/`

The ticket's rule says recipe keys go to `plugins/`. `sandbox:` is not a plugin (`recipe.md:277`: "`sandbox:` is not a plugin"), and `plugins/` is one page per plugin key.

`reference.md` is the page that already documents non-plugin recipe keys (`runtime.budget`, `runtime.limits`), so it is the one that owns this topic. Inside the chapter, the rules shrink to one sentence: entries only add, paths are `~/…` or absolute, a protected path is refused. Add a link to the new `reference.md` heading.
