## Where the ticket's table and the code disagree (the code wins, so correct the table)

1. **A restart has two names, one per layer, and the row should give both.**
   - Inside the pass it is `PassNext` `{ _tag: 'Requeued', cause: { _tag: 'Restart', restart } }` (`packages/domain/src/pass-next.ts:57-67`; produced at `packages/domain/src/routing.ts:143`).

2. **A person's requeue is never a `Requeued` `PassNext`.** It is `TicketReleased{cause: {_tag: 'ByPerson', waitId}}` (`packages/conductor/src/resolve-wait.ts:715`). It spends no restart because only `cause._tag === 'Restart'` is counted (`pass-next.ts:373`; `packages/domain/src/read-model.ts:551`).

But the-pass's own glossary rows say `round` lives under `implement:` and `restart` under `claim:` (`scripts/the-pass.py:347-350` and the English rows at `doc/the-pass.html:400`). That is wrong by the code. Fix those cells while you are in the script, in both languages. It is a doc correction, not a rename.
