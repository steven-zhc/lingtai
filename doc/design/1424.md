**Design note: #1424, the reading time in 0112 §14 and a new figures rule**

**Put the new rule at the end as §21. Do not insert it after §14.** 0112's rules are numbered 1–20 (`doc/decisions/0112-the-site-projects-the-repository.md:26-127`), and other files cite them by number:
- `apps/site/unit/docs.test.ts:231` cites §14: *"The cap is 0112 §14's 800 (#1411)"*.
- `doc/design/1378.md:15` and `doc/design/1410.md:20` cite §15, and `doc/design/1383.md:22` cites §16.
- The ticket's own *Out of scope* cites §20 for the frozen slogan.

If the rule went in as §15, every one of those citations would point at the wrong rule. #1376 made the same choice when it added §13–§20 (`doc/design/1376.md:3`: *"Leave it alone and keep its number, because other files may already cite it"*). Follow the house rule in `CLAUDE.md`: a changed decision is an edit to its topic's ADR, so this is an edit and not a superseding file.

**The §14 edit.** Keep the first sentence exactly as it stands (`:107-108`). Add the reading time after it: 5–6 minutes to read, and under 10 for a reader who runs the commands. This matches chapter 1's *"about ten minutes"* in §13's table (`:93`). Say that the reviewer judges the reading time the same way they judge the word cap. Do not give a words-per-minute figure, because that would make the reading time a second count. End by pointing to §21 for figures, with the line that a figure never raises the 800.

**§21's content**, as the ticket lists it. These are the points the ticket does not spell out:
- **Alt text is counted.** `proseOf` (`docs.test.ts:121-125`) removes only fenced code and then splits on whitespace. So the alt words count, and so does the `(img/….svg)` token. Say "one sentence" in the rule and give no number.
- **Name.** The name is `<chapter-file>-<what>`, where `<chapter-file>` is the chapter's file name without `.md`. Examples: `team-flow.svg`, `tutorial-board.png`. The whole name must match `[a-z0-9-]+\.(svg|png)`, or the route will not serve it (`apps/site/src/lib/doc-images.ts:8-12`). The rule applies to new files only. `concepts.svg`, `sandbox.svg` and `recipe.svg` keep their names: `doc/concepts.md:16`, `doc/safety.md:9` and `doc/tutorial-more.md:45` link to them, and renaming is out of scope.
- **SVG.** Draw it by hand in the house style of `doc/img/concepts.svg`: `role="img"`, `<title>`/`<desc>`, the `:root` variables and the dark-mode block. The alt text equals the SVG's `aria-label` or `<desc>`, the same rule `page.test.tsx:228` holds `safety.md` to. Keep the existing link line, *"Open the diagram at full size"*.
- **PNG.** Take it from a real run, never from `doc/milestone/…`. Draw ①②③ into the image, and put a numbered list under it with one line per number. Add no full-size link: `resolveHref` rewrites only `^img\/[a-z0-9-]+\.svg$` (`apps/site/src/lib/docs.ts:504`), so the link would go to GitHub. Do not name a new PNG `shot-*`. That prefix belongs to the home page (`apps/site/src/app/shots.tsx`, frozen by §20).
- **No chapter text or image changes in this ticket.** A chapter takes on §21 when its own ticket rewrites it.

**Consequences (`:140-142`).** This section needs two edits:
- The bullet says chapters are *"reviewed against §14–§17"*. Make it §14–§17 and §21.
- The same bullet says *"No test counts the words, so the reviewer is the only check"*. That is no longer true: `docs.test.ts:232` counts the words in `tutorial.md`. Change it to say a test counts the words of the chapters that have one, and that no test counts the reading time or the figures. The reviewer is the check for those.

**Checks.** The only file this touches is `doc/decisions/0112-…md`, and no test reads it. So `pnpm typecheck` and `HOME=/nonexistent pnpm test` stay green because they cannot see the change, not because they prove anything about it. No integration test applies either. The commit line takes the ADR form `0112: …`, for example `0112: a chapter reads in 5–6 minutes, and a flow or a board page is a figure`.
