**1. The schema and the fold are already in place, so this is a one-type swap.** `TicketContinued` is `{ runId, worker }` (`packages/domain/src/events.ts:226-229`). `applyTicket` folds it in the same case as `TicketClaimed` (`packages/domain/src/ticket.ts:268-269`). Those are `lifecycle` equal to `{ status: 'claimed', runId, worker }` and `runs` equal to `['pass-3']`. Write the payload as `parsePayload('TicketContinued', { runId, worker })`. Leave out `title` and `kind`: ADR 0109 §5 says it *"carries no title and no kind"*.
