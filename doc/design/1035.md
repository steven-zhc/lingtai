## Design note: #1035, the `exec` form of the kill test's `run:` line

The ticket already gives the shape. It is a change of one line, plus the docblock at `apps/cli/integration/telegram.test.ts:294-299`. This note covers one point the ticket does not state.

**`exec` only works because `shipped.run` is a single simple command.** The test reads `shipped` from the recipe (`telegram.test.ts:49-54`). Today that is `run: node packages/telegram/src/cli.ts` (`.lingtai/config.yaml:431`).

- Because it is a single command, `exec ${shipped.run}` replaces the shell with `node`. The process keeps the shell's pid, so `$$` is the pid that gets killed, and it keeps the shell's stdin, so the payload arrives.
- If that line ever became compound (`cd x && node …`, `a | b`, `FOO=1 node …; …`), `exec` would apply only to its first command. The pid written to the file would then belong to the wrong process, or the shell would exit early.

Do not guard against that in the code. Say it in the docblock in one clause, something like "`exec` keeps the shell's pid and stdin, so this assumes the shipped `run:` is one simple command." Then whoever changes `config.yaml:431` sees the assumption when this test times out.

**Keep the order: `echo $$ > ${pidFile}; exec ${shipped.run}`.** The pid has to be written before the `exec`, because nothing after it runs.

**Do not add a `wait`.** The `wait $!` in the old line is gone with the background job. The shell is the extension now, so its exit is the extension's exit. A SIGKILL comes back as `code === null`, which `packages/actions/src/command.ts:390-396` treats as a failure, and the test waits for that at `:313`.

**Verification:**
- The only check that runs this test is `pnpm exec vitest run --project integration apps/cli/integration/telegram.test.ts`. It runs one file, not the 803-second half, so it is within reach of the pass.
- The stand-in for CI's dash is the ticket's `/bin/dash` one-liner.
- `pnpm fmt:check`, `pnpm lint`, `pnpm typecheck` and `pnpm test` do not exercise this test. They only need to stay green.
