# Design note: #856, the word *attempt* in ADRs 0100–0110 and the two zh translations

This is a prose edit, and most of it follows from the ticket. Four things don't, and they are decided here.

## 1. Each H1 title copies its row in `doc/README.md`, word for word

Three H1s carry the word: `0102:1` (*"stopping drains the pass"*), `0103:1` (*"a pass is ten fixed steps"*) and `0108:1` (*"a crash stops the pass"*). The H1 counts as part of the body. Rewrite it, but don't make up new wording. t25f/g already rewrote the index:

- `doc/README.md:90` says 0103 *"an attempt is ten fixed steps"*.
- `:95` says 0108 *"a crash stops the attempt"*.
- `:89` says 0102 *"stopping drains the **turn**"*. That one is wrong: shutdown waits for every attempt in flight (0102 §8, and `work-loop.ts` awaits their settlement), not for the scheduling turn. 0102's H1 says *attempt*. `doc/README.md` is outside this ticket's set, so its row 89 is listed in the commit body for the operator.

The zh H1 at `zh/0058:1` (*"一趟 pass 有十步"*) becomes *"一次尝试有十步"*. Ticket numbers, links and the 0103 filename stay as they are.

## 2. A backticked code name is updated to what the code calls it now

An ADR states the current decision, and these names were renamed under t25b. Four are now stale:

| ADR cites | the code today | where it is cited |
|---|---|---|
| `passCeiling` | `attemptCeiling`, defined at `packages/conductor/src/ceiling.ts:58` | `0106:140`, `0108:102`, `zh/0058:156` |
| `passClientOf` | `ticketedClientOf`, defined at `packages/conductor/src/ticket-store.ts:313` | `0109:70` |

Change them. The ticket's "Done when" only lets *pass* stay as a verdict or verb, an event or file name, a link, or quoted history, and a stale function name is none of those.

These names stay in backticks:

- **Event names:** `PassRestarted` (`0108:90`, `0109:232`) and `PassRouted` (`0110:273`). They are listed under *never renamed*.
- **The `spend` column:** `pass` at `0110:232`.
- **Verdicts:** `passed` (`0103:57`) and `StepPassed`.

The prose right next to them still gets the new word. At `0110:232`, *"(null off a pass stream)"* becomes *"(null off an attempt stream)"*; the column name `pass` before it stays.

Before writing any other identifier, run `git grep` on it. A name stays unchanged only if a definition for it still exists.

## 3. Links and the mermaid diagram in zh/0058

- **Archive links stay:** `0039-the-worktree-is-the-whole-of-a-pass.md` (`zh/0058:290`, `:342`). It is a filename, and the archive is out of scope. The link text beside it at `:341`, *"工作树就是一趟 pass 的全部"*, is a title quoted from that file. Leave it unchanged and list it as quoted history.
- **Diagram, line 196:** `PO -->|"pass"| MG` is the verdict (proposed passes, so it merges). Keep it.
- **Diagram, line 202:** *"a fresh pass"* means a new attempt. It becomes *"a fresh attempt"*. It is English inside a zh file because the label is shared with the English drawing, so it stays English.
- **No anchors move:** nothing links to a heading in these files by a `#…pass…` anchor. `git grep -nE '01(0[0-9]|10)-[a-z-]+\.md#[a-z0-9-]*pass'` finds nothing in `doc apps packages scripts`.

## 4. The Chinese word is 尝试, and 一趟 goes with the old word

In the zh files, *pass* used as a noun shows up as `一趟 pass` (`zh/0058:57`, `:151`, `:224`, `:348`). It becomes `一次尝试`. Don't leave `一趟尝试`, which counts the old way.

`zh/0058:287` and `:364` already say 尝试. Leave them alone.

For *turn* in the zh files, don't coin a term. If a sentence means the loop's turn and no translation already uses a word for it, keep the sentence as it is and list it.

## The commit

This is one hand commit, with no `.git-blame-ignore-revs` line. Its body lists every kept hit by `file:line` and why it was kept: verb, verdict, event, column, link, quoted history, or meaning would move. It also lists the four code names updated in §2, so a reviewer doesn't take them for scope creep.
