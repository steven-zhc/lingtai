# Design note: #857, the word *attempt* in ADRs 0111–0124 and zh/0123

This follows #856, and its design (`doc/design/856.md`) still holds: H1s count as body, stale code names are updated, links stay, and 尝试 is the Chinese word. Below is what is new in this set.

## 1. Titles: only 0122's H1 changes, and it copies the index

`0122:1` reads *"Several passes share one conductor"*. `doc/README.md:108` already reads **"Several attempts, one conductor"** and *"a drain waits for every attempt"*. Rewrite the H1 to say *attempts* using that row's wording. The file name `0122-several-passes-share-one-conductor.md` stays, and so do the links to it (`0110:248`, the `(0122)` in `0124:108`). No other H1 in the set contains the word.

## 2. Each document's **Words** paragraph is rewritten first

Two documents define the word, and the rest of the file is worded from that definition:

- **`0122:11-15`.** It defines a **pass** as *"one ticket's ten steps"*. It then defines a **look** as one iteration of the work loop, and adds that *"the code's own comments call it a pass, and this ADR does not"*. That last clause is no longer true: the code says *turn* since t25b (`projectsForTurn`, `TurnReason`). Rewrite it so that:
  - an **attempt** is one ticket's ten steps, keeping the link to `0103-a-pass-is-ten-fixed-steps.md`;
  - a **look** is one turn of the conductor's loop (*turn* in the code), with `options.pass` named as the property it calls. `options.pass` is a property key (`packages/daemon/src/work-loop.ts:534`), so it stays in backticks.

  **Keep the word *look* everywhere else in 0122.** The ticket covers *pass* only, and swapping *look* for *turn* across the body would be a different edit.
- **`0123:16`** (*"A **pass** is one claim of it"*) and **`zh/0123:11`** (`一遍（pass）`) become **attempt** and `一次尝试`.

## 3. zh/0123: 遍 is the old word too

The six Latin *pass* hits are not the whole problem. zh/0123 counts attempts with **遍** throughout: `跑了几遍` (:7), `任何一遍` (:33), `遍数` (:39, :59, :68, :90), `一遍` (:47), `两遍之间` (:49), and `三遍、每遍` / `4 遍` (:53). `:11` defines that word as the pass. #856 §4 found the same thing with 一趟, so this follows its rule: 遍 counting attempts becomes 尝试 (`尝试次数`, `一次尝试`, `跑了三次尝试`), so the file doesn't keep a retired word in Chinese. List each line in the commit body. Specific cases:

- `pass 流` (:41) becomes `尝试事件流`. That is what #856 wrote in zh/0110.
- `(pass, round)` (:40) stays. `pass` there is the `spend` column (0110 §11, `0110:232`).
- `reviews to pass` (:81) stays. It is the verb, and it is the panel's English name.

## 6. The one sentence whose reason depends on the old word

`0120:228`: *"Not _passed_: a pass is already the noun for one ticket's way from claim to end."* The decision is that the yield isn't called *Passed*, and that doesn't change. Once *pass* stops being the noun, though, the stated reason is false. Replace it with the reason that is still true and doesn't need history: *passed* is already the verdict word, as in `StepPassed` (`packages/conductor/src/run-attempt.ts:510`) and *"the review passes"*. Don't write *"was once the noun"*: an ADR states the current decision, not how it got there. Name this sentence in the commit body, because it is the one place where the edit touches a reason and not just a word.
