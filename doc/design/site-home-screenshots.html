The first question

Why not just give the agent the issue?

You can. Then the only proof it worked is the agent saying so. With Lingtai, you get the receipt you just watched.

Common questions

Will it break main?

Nothing lands until your checks and the cold review pass. If main is already broken, it stops and tells you, instead of spending money on a bug that isn't its own.

Will it run up a bill?

Every paid call is recorded. Set a daily limit and it pauses when the limit is reached, until midnight or until you resume it.

Will it loop forever?

No. Each ticket gets a fixed number of fix attempts. When they run out, it stops and asks you what to do, with a suggested answer.

What if my laptop restarts at 3am?

Nothing is lost. Its commits are saved on a branch, and the next run carries on from there.

Can it weaken its own checks?

No. Your rules live outside the repository the agent edits, so it can't change them.

Can it read my ~/.ssh?HONEST ANSWER

By default, yes. A Claude Code agent runs as your user, so it can read what you can. Lingtai keeps its own secrets away from the agent, but it is not a sandbox. If you need one, run it inside yours. What an agent can touch →

Not a sandbox · runs on one machine · not yet 1.0 — what it needs, and what it doesn't do yet →

Lingtai runs on one machine of yours. It keeps its state in a local SQLite file by default, alongside a clone of each repository it manages and the agent processes it starts. There is no hosted service and nothing to sign up for — install the CLI and run lingtai init.

Built in the open. Source, releases, and issues live on GitHub.
