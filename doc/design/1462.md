## Decisions

1. **The walker is `rulesOf` from `apps/board/test/css-rules.ts`, not `pr-colours.test.ts`'s `scan`.**
   - `scan` (`pr-colours.test.ts:16`) narrows to `PREFIXES = ['.pr-', '.prp-', '.obs-']`. It is a filter on top of `rulesOf`, not the walker. The ticket's "factor it out" already happened in `test/css-rules.ts`, whose header says *"Walks every block of a stylesheet at any depth, comments stripped … `chain` is its selector and every enclosing one"*.
   - Don't touch `pr-colours.test.ts`.
   - Model the new file on `unit/card-radius.test.ts`, which is the same kind of guard for radii. Copy three things from it:
     - exported pure functions over a `source: string`, so the planted-literal cases call them directly (`card-radius.test.ts:43,48`);
     - `rootRules` / light / dark found by `chain` (`card-radius.test.ts:53–55`);
     - a `MARKS`-style list with reasons.

2. **Read every declaration in a body, not the first.** `card-radius.test.ts:41`'s `RADIUS` regex is used through `exec`, which returns one match. A rule can carry both `font` and `font-size`, and a minified one like `.hfr-hero b{…}` (`globals.css:3218`) is a single body. Split `r.body` on `;` and match the property name exactly (`font` or `font-size`), so `font-family`, `font-weight` and `font-variant-numeric` never match.

3. **The `font` check removes `var(...)` before looking for a unit.**
   - Use `/\d*\.?\d+(px|rem|em|%|vw|vh|pt)\b/` on the value with every `var\([^)]*\)` removed first. Then `var(--fs-2xs)` and `var(--fs-2xl)` can never be mistaken for units.
   - A unitless line-height (`/1.15` in `.stat b`) passes.
   - `inherit` passes both properties: 10 `font: inherit` and 3 `font-size: inherit` exist today.
   - Exempt rules by `chain`: one includes `:root`, or one includes `prefers-color-scheme: dark`. That exempts the whole dark block, as the ticket asks, not just the `:root` inside it.

4. **Assertion 3's display list has three entries:** `.ld-date .dn`, `.hfr-hero b`, `.handled-n b`.
   - This is the ticket's own Edge ("where one of them deleted a rule, skip it") applied to its test, not a loosening of the test.
   - Check the list both ways, as `card-radius.test.ts`'s *"keeps every mark in the list a live rule"* does: a fifth user fails by selector, and a listed selector that no longer uses it fails too.
   - Say this in the commit body: `.ld-header h1` was retired by `415d24223`.

5. **Assertion 4's floor is 340, not 350, and the ticket's 386 is not reachable.**
   - Measured with the same walk, the file after this change has 346 size declarations that read a variable. The ticket's figure was an estimate made before #1459–#1461 deleted rules.
   - The floor exists to catch a walker that silently reads nothing, so put it a little under the measured count. Write the measured 346 in the test's comment.
   - Don't add rules to reach 350. Don't count `inherit` toward it.
   - If the implementer's count after conversion differs from 346, use their count and say so in the commit.

6. **The `.tsx` scan reuses `client-graph.test.ts`'s `filesUnder`.**
   - `filesUnder` is at `client-graph.test.ts:63–66`: a `readdirSync` recursion for `/\.tsx?$/`. Copy it, since it is not exported.
   - Reading the repository's own files with `readFileSync` is already accepted in the unit half: `pr-colours.test.ts:9`, `card-radius.test.ts:11`, and that walker all do it. This stays a unit test, and `HOME=/nonexistent` does not reach it.
   - What counts as a hit:
     - any `fontSize=` attribute;
     - any `fontSize:`, `font:` or `font-size:` whose value, after the `var()` removal from decision 3, has a number with a unit.
   - Exempt the two paths by name, each with its reason, as an `EXEMPT: { path, why }[]` that must still exist. `markdown-preview.ts`'s `'0'` has no unit and would pass anyway, but list it as the ticket asks so a later `'0px'` there still reads as deliberate.
   - Export the matcher and plant a `.tsx` string in the self-test (`<text fontSize="11">`, `style={{ fontSize: '12px' }}`).

7. **The mode-graph rule goes immediately after `.src`** (`globals.css:3666`), before the `@media (max-width: 900px)` line at `globals.css:3667`.
   - `svg.mode-graph text` has specificity (0,1,2). Nothing else sets `font-size` on `.mode-graph` (`globals.css:3089–3090` set colour only), so it wins without `!important`.
   - Remove only the `fontSize` attributes from the five `<text>`s and leave `fill="currentColor"`.
   - `app/mode-graph.tsx` (the one adding a repository uses) is untouched.

8. **The planted cases in assertion 5 also cover nesting and the shorthand.** Use the ticket's four plus `.x { &:hover { font-size: 11px } }`. Each failure is reported as `selector { property: value }`, like `card-radius.test.ts:51`, so a red names its rule.
