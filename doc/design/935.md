# Design note for #935: brief a granted `FixerDisagrees` round with the declined findings

## Where the change goes

There are three places, and data moves in one direction:

1. **`grantCriterion(reason, refusal?)`** in `packages/domain/src/wait.ts:366`. This is the only place that decides which findings the round gets.
2. **The continuation** in `packages/conductor/src/conduct.ts:1168-1176`. It passes a refusal that is still standing, and carries the fixer's answer on as a new continuation field.
3. **`fixBriefParts`** in `packages/conductor/src/fix.ts:472`. A new optional input renders the fixer's answer under its own heading.

`SentBack` and `runAttempt` do not change. The fixer's answer goes around them, as `advice` already does. `continuation.advice` is read straight into `fixBriefParts` inside `fixRound` (`conduct.ts:4012`: `...(continuation?.advice === undefined ? {} : { advice: continuation.advice })`) and never travels through `options.from`. Put the new field on the same path. `SentBack` (`packages/actions/src/action.ts:464-471`) is shared by every sent-back step. Adding a fixer-only field to it would put a field on the actions package that only one caller reads.

## 1. `grantCriterion`

The return type gains one optional field, `declined?: string`: the fixer's `said`, unclipped beyond what it already is. The `FixerDisagrees` arms change. These are the direct arm at `:382-385` and the `ProposedEscalated` arm at `:405-408`; the `AgentCrashed` arm reaches them through the recursion at `:369`. Rules, in order:

- **`said` is empty → `null`, as today.** The offer depends on this. Today's rule is "a criterion exists iff `said` is non-empty", and that has to stay true with or without the second argument. Otherwise the Watch-out's *"the same yes/no it answers now"* breaks. The refusal never turns a `null` into a grant or a grant into a `null`.
- **The refusal counts only if `refusal.key.startsWith('review:')` and at least one finding has a non-blank `failureScenario`.** The key is written as `` `${d.outcome.step}:${action.name}` `` (`attempt.ts:520`). A `run:` at `build` also yields a verdict (`packages/actions/src/process-action.ts:58`), so a red build writes `refusal` with a `build:` key. The key check is what keeps a build refusal out of a review-shaped brief. In that case: `{ printed: { step: 'review', detail: 'Fix the recorded review findings.' }, findings: refusal.findings, declined: said }`. This uses the same words as the `ReviewFindings` arm at `:391-393`.
- **Otherwise** (no refusal, a non-review key, or no actionable finding): `{ printed: { step: 'review', detail: <a sentence saying there is no recorded review finding to fix, and that the previous fixer's answer below is why the pass stopped> }, findings: [], declined: said }`. The detail must not contain `said`. The Done-when asks for *"a `printed.detail` that is not the fixer's `said`"*, and that applies to this branch too.

`allowedResolutions` calls `grantCriterion(reason)` with no second argument. Because of the first rule, it gives exactly today's answers. The function's own comment (*"One function for both the offer … and the brief … so they cannot drift apart"*, `wait.ts:362-363`) still holds.

**About the ticket's Want, "with no recorded refusal, no round is offered":** the Watch-out, the Edges and the Done-when all say the offer is unchanged, so this note follows them. The offer cannot see attempt state, so it cannot make that distinction. The brief says so instead.

## 2. The caller, `conduct.ts:1168-1176`

- Compute the criterion once, as `const criterion = granted ? grantCriterion(reason, standingRefusal(runState)) : null`. Today it is called three times; with two arguments, three calls would be three chances to pass different things.
- **"Belongs to this run" is already true by construction.** `runState` is `reduceAttempt(await store.read(options.continuing.runId))` (`conduct.ts:1127-1128`), which is that run's own stream. No run-id check is needed.
- **"Still standing" is not true by construction, and the caller has to check it.** `refusal` is *"Not cleared by a later pass or a new head"* (`attempt.ts:188`). Take this case: review refused, round 1 committed, review passed with minors, and a round on those minors changed nothing. `refusal` then still names the first review's findings, which were already fixed. Pass the refusal only if `runState.steps[refusal.key]?.verdict === 'failed'`. `steps` is *"Latest verdict per gate name"* (`attempt.ts:152`), and `verdictOf` maps `refused` to `'failed'` (`attempt.ts:276`). Otherwise pass `undefined`, and the no-finding branch above applies.
- Make the check a small exported function next to the reducer, `standingRefusal(state: AttemptState)` in `packages/domain/src/attempt.ts`, so it can be unit-tested without a conductor.
- Put `criterion.declined` on the continuation (for example `declined?: string`) next to `advice`. Like `advice`, it is only for a granted lap. The comment at `:1163-1164` (*"Only a granted lap: it is one round long"*) is the reason, and it covers this field too.

## 3. The brief, `fixBriefParts`

Add an optional input `declined?: string` and render it as its own section after `${evidence}`, next to `adviceSection`. The heading must say whose words these are, for example `## What the previous fixer answered, which is not the review`. Under it, the text in a fence and one sentence: the findings above (or their absence) are the criterion, this text is context, and the fixer may disagree with it.

- **With findings:** `fixRound` already picks `{ on: 'findings', findings }` when `brief.context.recheck` is non-empty (`conduct.ts:3949-3952`). `recheck` is seeded from `options.from?.findings` (`run-attempt.ts:1248`). So the findings reach `findingsHalf` under `## The findings` with no extra wiring; only the `declined` section is new.
- **Without findings:** the refusal falls through to `{ on: 'output', output: said }`, where `said` is `printed.detail` (`conduct.ts:3951`). That output is the "no recorded finding" sentence, and the declined section follows it. `outputHalf` will title it as what the `review` action printed. Make the sentence itself carry the meaning so it reads correctly under that heading. Do not add a fourth `refusal.on` shape for it.
- Set `declined` only from `continuation?.declined`. An ordinary round in the same pass never has one.

## Tests (unit only, no store)

- In `packages/domain/unit/wait.test.ts` (it already imports `grantCriterion` at `:15`), write a matrix of both `FixerDisagrees` shapes × {review refusal with an actionable finding, `build:` key, no refusal, findings with blank scenarios}, asserting `findings`, `printed.detail !== said` and `declined === said`. Also check: an empty `said` with a review refusal → `null`. And `allowedResolutions` for both shapes includes `GrantFixRound` exactly when it did before the change. The crash recursion test at `:1187` must still compare equal.
- Add a `standingRefusal` test: a refusal whose key's latest step verdict is `passed` → `undefined`.
- In `packages/conductor/unit/fix.test.ts`, use the existing `fixBrief({...})` fixtures (`:200`). With findings and `declined`, the findings appear under `## The findings` and the `said` text appears only under the fixer's heading. With `on: 'output'` and `declined`, the brief has no `## The findings` section.

## Edges this note decides

- **A read that fails:** `store.read` at `:1127` already sits inside the continuation's promise, and this adds no new read.
- **A null or unknown value:** `refusal` is `null` (no refused verdict in the run), or the key is unrecognised. Both go to the no-finding branch, and that branch never invents a finding.
- **Restart, two passes, pause, stale page:** none apply. This is a pure function, a pure reducer read and a prompt.
- **Snapshots and stored events:** `declined` lives only on the in-memory continuation and in the prompt text, so there is no schema or event change. The prompt is recorded through `recordPrompt` as it is today (#923).
- **The ADR:** 0118 §1 (*"no criterion for a fixer means no grant"*) is untouched. The offer's yes/no is unchanged, and the criterion handed over is now the findings.
